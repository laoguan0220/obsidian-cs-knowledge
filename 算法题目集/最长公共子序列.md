#映射的思想
由映射关系将第二个数列 由第一个数列进行转化 第一个数列我们其实可以认为是1 2 3 4 5
第二个数列我们可以认为是 3 2 1 4 5最长公共子序列其实是求的第二个数组的最长上升子序列 所有的只是数排列的顺序发生了改变我们都可以这样求解 
 公共子序列的要求：选出的数在 P1 和 P2 中出现的先后顺序一致。

  经过重新标号后：
  - P2 的顺序变成了 1, 2, 3, 4, 5（天然递增）
  - 我们只需要在 A（即重标后的 P1）中选一个递增子序列，这个子序列对应的数在 P2 中自然也是按顺序出现的

  所以：P1 和 P2 的 LCS = A 的 LIS。
