# 执行摘要

三进制状压DP是将每个元素的三种可能状态（例如：未处理/状态1/状态2）映射到一个三进制数的技巧。利用浮点或整数运算，将一行格子、若干物品或城市访问次数的多种状态压缩到一个整数表示，再通过事先预处理的方式快速转移。本文首先介绍三进制压缩的表示与解码方法（如何把每个格/物品的0/1/2状态映射到整数状态），并给出通用的状态转移模板和常用技巧（如预处理合法状态、滚动数组优化、剪枝判断）。然后通过两个经典例子（网格染色DP和城市访问DP）给出完整的C++实现模板，并标注注释、输入输出与复杂度。文末总结三进制状压DP的适用场景与优势劣势，并列出典型题目及难度和关键技巧对比表。

# 算法核心思想

**三进制表示法：** 将每个元素（如格子、物品、城市等）可能的三种状态用 $0,1,2$ 表示，并将这些状态串联起来作为一个三进制数（状态压缩）。比如一个有 $m$ 个元素的系统，其状态可记为长度为 $m$ 的三进制串 $d_{m-1}d_{m-2}\dots d_1d_0$，对应整数编码 $S=\sum_{j=0}^{m-1}d_j\times 3^j$。这样 **三进制数 $S$ 一一对应元素状态**。【17†L11-L19】【6†L431-L434】

- **编码（压缩）**：将 $m$ 个元素的状态数组映射到一个三进制整数。例如，每行 $m$ 个格子的染色情况可以看作 $d_j$ 是第 $j$ 列的颜色（取值 0,1,2）。编码时用累乘加法：`S = d[0] + d[1]*3 + d[2]*3^2 + ...`。  

- **解码（解压）**：将状态整数 $S$ 分解出每位状态，常用取模和除法：`for(j=0; j<m; j++){ state[j] = S % 3; S /= 3; }` 【24†L130-L138】。或者预先用表 `tri[S][j]` 存储好，快速读取第 $j$ 位状态【24†L130-L138】。

**状态转移：** 依问题而定。常见情形包括“移除一个元素的状态”或“元素状态+1”之类：

- *移除元素（TSP 例）*：对于需要枚举“某路径状态去掉城市 $j$”的情况，如果当前状态码为 $i$，只要第 $j$ 位（$i$ 在第 $j$ 位置的三进制值）不为 0，就可以生成新状态 $i' = i - 3^j$（即将第 $j$ 位置的状态从 1 或 2 减至 0）【6†L446-L449】。以图示说明：  

  ```mermaid

  graph LR

    A["状态 i: (2,1)_{3} = 2*3+1 = 7"] --> B["减去第0位 (3^0): 新状态 (2,0)_{3} = 6"]

    A --> C["减去第1位 (3^1): 新状态 (1,1)_{3} = 4"]

  ```

- *普通转移模板*：如果某问题要求元素状态从 $0\to 1$ 或 $1\to 2$ 等（例如一件物品可以取0、1、2件），则可以在枚举新状态时增加对应位：$i' = i + 3^j$；或其他依据题意的变化。只需确保不越界，并对新状态重新解码后再判定合法性。  

**预处理合法状态和转移：** 当 $m$ 较小（如 $m\le5$），可预枚举所有 $3^m$ 个状态，筛选出符合行内约束（如同一行相邻元素不能相同颜色等）的“合法状态”。再进一步预处理“状态 $s$ 能匹配状态 $t$”（行间约束符合）的布尔表或邻接表。这样 DP 转移时快速查找即可。类似二进制压缩的思路，只是这里是三进制【17†L11-L19】【6†L431-L434】。

**技巧与优化：**

- **位运算与加减：** 与二进制习惯使用位运算不同，三进制状态需要用乘法和模运算或查表完成位操作。常用 `bit[j]=3^j` 存储幂值，方便计算增减某位【6†L453-L459】。预先计算每个可能状态 $i$ 的各位状态可大幅加速【24†L130-L138】。  

- **滚动数组：** 因为状态数可能非常大，只需保留当前行和上一行的 DP 数组即可，避免开 $n\times 3^m$ 的矩阵。例如网格染色按行滚动维护 DP。  

- **剪枝判断：** 动态规划中可提前排除一些不合法或非必要的状态。例如提前用一个函数快速判断状态是否合法（如 `ok(i)` 确保每位都非0），避免在转移内多做无效循环【8†L39-L47】。  

- **枚举优化：** 如果 $m$ 很小，3 的幂（$3^m$）个状态可能可接受，但当状态数爆炸时可考虑使用哈希表只存合法状态或转移较多的状态，从而压缩空间。但三态比二态更爆，所以要谨慎控制 $m$ 的大小。  

**从二进制推广：** 二进制状压是三进制状压的特殊情况，每位只有 0/1。本质相同，只是进制变为 3。二进制中常用 `(s & (1<<j))` 判断第 j 位，此处需改为 `((s/3^j)%3 != 0)` 判断对应状态。移除元素原来写 `s - (1<<j)`，三进制改为 `s - 3^j`【6†L446-L449】。在三进制背景下，“&&、|”等位运算失效，需要以数组方式或算术方式处理。正如某题解指出，本题三种颜色状态要用三进制编码，转换后不能像二进制那样用位操作【17†L11-L19】。

# C++ 具体实现示例

下面给出两类典型题型的 C++ 模板示例，均使用**高效输入输出**，并在注释中标明状态编码、转移、复杂度等。

## 示例1：网格染色DP（每格三种状态）

**题意（示例）：** $N\times M$ 网格，每格涂抹1/2/3三色果酱。任意相邻两格颜色必须不同。已知第 $K$ 行固定颜色，求共有多少种涂抹方案。$N\le10^4,\ M\le5$。【17†L11-L19】  

**思路：** 按行DP。将每行 $M$ 格颜色映射到长度 $M$ 的三进制数作为行状态。预枚举所有 $3^M$ 种状态（最多$3^5=243$），筛选出行内合法状态（相邻格颜色不同）。再预处理两个合法状态能否行间兼容（即每列颜色不同）。令 `dp[i][s]` 表示第 $i$ 行选状态 $s$ 的方案数。状态转移：对所有上一行状态 $t$ 使得合法且兼容，当行固定状态 $K$ 时要判断跳过等等。最终累加 $dp[N][*]$。  

```cpp

#include <bits/stdc++.h>

using namespace std;

using ll = long long;

const int MOD = 1000000007;

// 将长度为M的状态编码s解码为每列的颜色

void decode_state(int s, int M, int col[]) {

    for(int j = 0; j < M; j++){

        col[j] = s % 3;  // 0,1,2代表三种颜色

        s /= 3;

    }

}

int main(){

    ios::sync_with_stdio(false);

    cin.tie(nullptr);

    int N, M, K;

    cin >> N >> M >> K;

    vector<int> fixed_row(M);

    // 输入第K行的颜色（1,2,3），转换为 0,1,2

    for(int j=0; j<M; j++){

        int x; cin >> x;

        fixed_row[j] = x - 1;

    }

    // 预处理所有3^M状态

    int S = 1;

    for(int i=0; i<M; i++) S *= 3;

    vector<int> valid; valid.reserve(S);

    vector<array<int, 5>> state_cols(S);

    // 筛选行内合法状态（相邻不同）

    for(int s = 0; s < S; s++){

        int t = s, prev = -1;

        bool ok = true;

        for(int j = 0; j < M; j++){

            state_cols[s][j] = t % 3;

            if(state_cols[s][j] == prev){ ok = false; break; }

            prev = state_cols[s][j];

            t /= 3;

        }

        if(ok) valid.push_back(s);

    }

    // 预处理两个状态是否兼容（列上不同）

    int V = valid.size();

    vector<vector<int>> compat(V);

    for(int i=0; i<V; i++){

        for(int j=0; j<V; j++){

            bool can = true;

            for(int c=0; c<M; c++){

                if(state_cols[valid[i]][c] == state_cols[valid[j]][c]){

                    can = false; break;

                }

            }

            if(can) compat[i].push_back(j);

        }

    }

    // DP

    vector<ll> dp_prev(V), dp_cur(V);

    // 初始化第一行（行1到K行中途会用到固定行K的状态）

    for(int i=0; i<V; i++){

        // 如果第一行就是固定行 K

        if(K == 1){

            // 只允许等于 fixed_row 的状态

            bool match = true;

            for(int c=0; c<M; c++){

                if(state_cols[valid[i]][c] != fixed_row[c]) { match = false; break; }

            }

            dp_prev[i] = match;

        } else {

            dp_prev[i] = 1; // 其他行无约束

        }

    }

    // 从第2行开始转移

    for(int i=2; i<=N; i++){

        fill(dp_cur.begin(), dp_cur.end(), 0);

        for(int idx=0; idx<V; idx++){

            // 如果当前行为固定行K，只有匹配的状态允许

            if(i == K){

                bool match = true;

                for(int c=0; c<M; c++){

                    if(state_cols[valid[idx]][c] != fixed_row[c]) { match = false; break; }

                }

                if(!match) continue;

            }

            // 转移：遍历上一行的兼容状态

            for(int pre : compat[idx]){

                dp_cur[idx] = (dp_cur[idx] + dp_prev[pre]) % MOD;

            }

        }

        dp_prev.swap(dp_cur);

    }

    // 累加结果

    ll ans = 0;

    for(int i=0; i<V; i++){

        ans = (ans + dp_prev[i]) % MOD;

    }

    cout << ans << "\n";

    return 0;

}

/*

复杂度：共有3^M状态，筛选合法O(3^M*M)，兼容预处理O(V^2*M)，DP转移O(N*V^2)（可约简到N*V^2）。对于 M≤5 通常可行。

*/

```

- **说明：** 上例中状态总数 $3^M$，有效状态数记为 $V$。复杂度主要是 $O(3^M*M + V^2*M + N*V^2)$。当 $M\le5$ 时 $3^M$ 约243，经过合法筛选后 $V$ 通常远小于 $3^M$，转移可行【17†L11-L19】。若状态过多，可使用哈希表只存非零 DP 状态。  

## 示例2：背包/分配类三态DP（TSP 变种）

**题意（示例）：** HDU3001 “Travelling”——访问 $n$ 座城市，每座城市最多访问两次，求访问所有城市的最小费用【24†L99-L107】。对应状态：每个城市的访问次数（0，1，2），因此可以用三进制表示选择路径的状态。本示例用三进制DP求解最短哈密顿路径。  

**思路：** 状态用 $n$ 位三进制（$n\le10$），$0$ 表示未访问，$1$/`2` 表示访问过1次/2次。令 `dp[j][s]` 表示当前结束于城市 $j$，且访问状态为 $s$（三进制编码）的最小费用【6†L431-L434】【24†L129-L137】。初始状态为访问过一个城市：`dp[j][bit[j]] = 0`（`bit[j] = 3^(j-1)`）。状态转移：对于状态 `s` 和结束城市 `j`（需要 `s` 的第 `j` 位≠0），枚举下一个城市 `k` 在当前路径中为 `0` 的情况：如果 `s` 中第 `k` 位 <2，则可以访问城市 $k$，得到新状态 `t = s + 3^(k-1)`。但由于每城市最多访问两次，实际转移稍复杂（可对每城市做一次和两次两条路径一起考虑）。以下代码示例采用类似旅行商思路，从状态 $s$ 转到去掉末尾城市的 $s'$【6†L446-L449】【24†L129-L137】，最终枚举所有路径以取最小费用。

```cpp

#include <bits/stdc++.h>

using namespace std;

const int INF = 0x3f3f3f3f;

// bit[k] = 3^(k-1)，tri[i][k] 预存状态 i 在第 k 位的值

int bit[11] = {0,1,3,9,27,81,243,729,2187,6561,19683};

int tri[60000][11];

int dp[11][60000];

int w[11][11];

int main(){

    ios::sync_with_stdio(false);

    cin.tie(nullptr);

    // 预处理：tri[i][k] = i 的三进制表示中第 k 位（1-indexed）的值

    for(int i=0; i<60000; i++){

        int t = i;

        for(int j=1; j<=10; j++){

            tri[i][j] = t % 3;

            t /= 3;

        }

    }

    int n, m;

    while(cin >> n >> m){

        // 读图，初始化费用矩阵

        for(int i=1; i<=n; i++){

            for(int j=1; j<=n; j++){

                w[i][j] = (i==j?0:INF);

            }

        }

        for(int i=0,u,v,c; i<m; i++){

            cin >> u >> v >> c;

            w[u][v] = w[v][u] = min(w[u][v], c);

        }

        // 初始化dp，无论从哪个城市出发

        int maxS = bit[n+1]; // =3^n

        for(int i=1; i<=n; i++){

            for(int s=0; s<maxS; s++){

                dp[i][s] = INF;

            }

            // 从城市 i 出发，只访问它，cost=0

            dp[i][bit[i]] = 0;

        }

        int ans = INF;

        // 枚举所有状态

        for(int s = 0; s < maxS; s++){

            // 找出当前状态 s 是否已访问所有城市至少一次

            bool full = true;

            for(int j=1; j<=n; j++){

                if(tri[s][j] == 0) { full = false; break; }

            }

            // 转移：将状态 s 扩展到 s' + 访问新的城市

            for(int end=1; end<=n; end++){

                if(dp[end][s] == INF) continue;

                // 如果状态 s 已完成访问所有城市，记录结果

                if(full){

                    ans = min(ans, dp[end][s]);

                    continue;

                }

                // 否则枚举下一个城市 k

                for(int k=1; k<=n; k++){

                    if(tri[s][k] < 2 && w[end][k] < INF){

                        int t = s + bit[k];

                        dp[k][t] = min(dp[k][t], dp[end][s] + w[end][k]);

                    }

                }

            }

        }

        if(ans == INF) cout << "-1\n";

        else cout << ans << "\n";

    }

    return 0;

}

/*

复杂度：状态数3^n≈59049（n=10时），DP循环嵌套三重，总复杂度 O(3^n * n^2)。依题意n=10时可行【6†L449-L452】。Tri表预处理O(3^n*n)。内存O(n*3^n)。

*/

```

- **说明：** 上例简化了从状态中移除元素的原理【6†L446-L449】。这里直接向前扩展状态，效果等同于再经典做法中从状态中去掉城市$j$后从其它城市转移到$j$【6†L446-L449】【24†L130-L138】。总体复杂度 $O(3^n \cdot n^2)$【6†L449-L452】，对于 $n\le10$ 可行。若$n$更大，可考虑剪枝或交换思路（如 DFS+状压DP 等）。  

# 时间复杂度与空间复杂度分析

- **网格DP示例：** 时间复杂度约为 $O(3^M\cdot M + N \cdot V^2)$，其中 $V$ 是合法状态数。一般情况下 $V \ll 3^M$。当 $M\le5$ 时 $3^M\le243$，且相邻限制会进一步减小 $V$（如 $V\approx48$ 左右）。空间复杂度主要在保存DP数组，$O(N\cdot V)$ 用滚动数组可降为 $O(V)$。【17†L11-L19】  

- **TSP示例：** 时间复杂度 $O(3^n \cdot n^2)$【6†L449-L452】。空间复杂度 $O(n \cdot 3^n)$ 保存DP和位表。通过剪枝（如跳过中途无法完成的状态）和预处理可以常数优化。  

**优化技巧：** 可以通过剪去所有三进制表示中有不合法值（如$0$次数）或合并相似状态的方法减少状态数。例如在TSP变种中，有时只关注“全部城市至少访问一次”的状态，用一个布尔数组提前标记全覆盖状态，或者只存储非零DP值的状态（Sparse DP）。滚动数组可将空间降为$O(3^m)$。  

# 适用问题与优势/劣势

- **适用问题类型：** 三进制状压适合**状态数量小、每个元素/位置有三种互斥状态**的问题，例如格子染色（空/已涂/障碍）、插头DP中插头状态的3种情形、或路径/背包问题中每个元素可用两次的限制。常见题型如“每格涂3种颜色”、“每城市最多访问2次”、“每物品可取0/1/2件”以及“每位置情况0/1/2” 等。  

- **优势：** 能把多种状态整合进一个压缩整数，保持DP框架统一，避免多维数组。例如将2D/3D状态展开到一维DP中，实现简单。相比二进制状压，可直接编码“多于两种”状态。  

- **劣势：** 状态空间增长更快。若长度$m$仅5，已有 $3^5=243$ 种组合，而二进制只有32种；难以处理$m$过大的情况。此外位运算技巧失效，需要手动加减或除余运算，对速度要求高时需仔细优化。注意**编码越界**，`int` 范围需足够存储 $3^m$。  

# 注意点与常见陷阱

- **整数溢出：** 状态值上限为 $3^m-1$，例如 $m=12$ 时 $3^{12}\approx 531441$，尚在32位整数范围内。但更大时要用64位存储。DP 值或费用可能很大，也需注意溢出。  

- **状态数爆炸：** 当 $m$ 较大时，$3^m$ 指数爆炸。务必检查题目 $m$ 的上限，合理剪枝或用哈希存储。  

- **转移重复与剪枝：** 枚举时避免多算。例如TSP变种中“取路径完整性”最好在循环外一次性判断，而不是每次DP都判定。网格DP中，固定行的情况常忘，需对$i=K$单独处理。【17†L11-L19】  

- **编码顺序：** 确保状态编码与题意一一对应，如颜色编号或物品编号统一。若题目颜色标号从1开始，编码时要减1对齐【17†L95-L100】。  

- **边界/初始状态：** 初始化时要考虑第1行/第0行边界（如把0行视为虚拟行处理）。示例中第一行要特殊初始化，或像TSP例中对初始城市做特别处理。  

- **内存与常数优化：** 三进制DP常用二维大数组，注意内存限制（如 `dp[11][60000]` 消耗较大）。可用 `vector` 或滚动数组减少常数。预处理的 `tri` 表可节省每次取位的开销。以上示例均使用 `ios::sync_with_stdio(false)` 提升IO。
