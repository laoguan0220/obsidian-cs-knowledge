# 扫描线核心思路

1.  确定扫描方向 - 通常是 X 轴从左到右，或按时间线推进
2.  定义事件点 - 什么位置/时刻需要处理（线段起点、终点、交点等）
3.  维护活跃状态 - 扫描线当前"穿过"了哪些东西
4.  在事件点更新状态并产生结果

---

## 常见应用场景

| 场景 | 扫什么 | 为什么好用 |
| :--- | :--- | :--- |
| 矩形面积并（Union Area） | 沿 X 轴扫，每个矩形的左右边是事件 | 把 2D 问题降成 1D：每次只算当前被覆盖的 Y 区间长度 × X 增量 |
| 线段交点检测 | 沿 X 轴扫，线段端点是事件 | 只需检查 Y 坐标相邻的线段是否相交，而不是 O(n²) 暴力两两比对 |
| 区间最大重叠 | 沿时间线扫，每个区间的开始/结束是事件 | 会议室预定、最大并发连接数等问题，O(n log n) 解决 |
| 多边形填充（图形学） | 逐行扫描，边与扫描线的交点是事件 | 判断像素在多边形内部还是外部 |
| 天际线问题 | 沿 X 轴扫，建筑物左右边是事件 | 维护当前最高高度，高度变化时输出关键点 |

---

## 一个简单例子
计算多个区间的最大重叠数：
- 把每个区间拆成 `(起点, +1)` 和 `(终点, -1)` 两个事件
- 按坐标排序，扫描过去，维护当前重叠计数，取最大值

```cpp
// 区间最大重叠 - 扫描线思路
// events: [(x, +1), (x, -1), ...] 排序后扫描
for (event in sorted_events) {
    count += event.delta;
    max_overlap = max(max_overlap, count);
}
````

## 一句话总结

扫描线本质是 "只关心变化点的遍历" - 把连续问题离散化为事件序列处理，通常能将 O (n²) 暴力降为 O (n log n)。当你遇到 "在某个维度上有起点和终点" 的问题时，就值得考虑扫描线。
