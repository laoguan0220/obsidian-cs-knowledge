## 费马小定理与组合数求模

### 1. 费马小定理

**费马小定理**（Fermat's Little Theorem）指出：如果 $p$ 是质数，且 $a$ 是整数，$a$ 不被 $p$ 整除，则：

$$a^{p-1} \equiv 1 \pmod{p}$$

等价形式为：

$$a^{p-2} \equiv a^{-1} \pmod{p}$$

这个等价形式告诉我们，当模数 $p$ 是质数时，$a$ 的**模逆元**就是 $a^{p-2} \bmod p$。

### 2. 什么是逆元

**逆元**（Modular Inverse）是数论中的重要概念。

**定义**：对于整数 $a$ 和模数 $m$，如果存在整数 $b$ 使得：

$$a \cdot b \equiv 1 \pmod{m}$$

则称 $b$ 是 $a$ 模 $m$ 的**逆元**，记作 $a^{-1} \pmod{m}$ 或 $\text{inv}(a)$。

**直观理解**：在模运算中，逆元相当于"除法"。因为模运算中不能直接做除法，所以用乘以逆元来代替。

**存在条件**：$a$ 模 $m$ 的逆元存在当且仅当 $\gcd(a, m) = 1$（即 $a$ 与 $m$ 互质）。

### 3. 用费马小定理求组合数

组合数公式为：

$$\binom{n}{k} = \frac{n!}{k!(n-k)!}$$

当我们需要计算 $\binom{n}{k} \bmod p$（$p$ 为质数）时，由于模运算不能直接做除法，需要将除法转化为乘以逆元。

**计算步骤**：

1. **预处理阶乘**：
   $$fact[i] = i! \bmod p$$

2. **预处理阶乘的逆元**：
   利用费马小定理：
   $$inv\_fact[n] = fact[n]^{p-2} \bmod p$$
   
   然后递推：
   $$inv\_fact[i-1] = inv\_fact[i] \cdot i \bmod p$$

3. **计算组合数**：
   $$\binom{n}{k} \bmod p = fact[n] \cdot inv\_fact[k] \cdot inv\_fact[n-k] \bmod p$$

### 4. 完整推导

**为什么这样可行？**

因为：
$$\binom{n}{k} = \frac{n!}{k!(n-k)!}$$

在模 $p$ 下：
$$\binom{n}{k} \equiv n! \cdot (k!)^{-1} \cdot ((n-k)!)^{-1} \pmod{p}$$

其中 $(k!)^{-1}$ 表示 $k!$ 模 $p$ 的逆元。

由费马小定理：
$$(k!)^{-1} \equiv (k!)^{p-2} \pmod{p}$$

### 5. 代码实现示例

```python
def mod_comb(n, k, p):
    """计算 C(n,k) mod p，p 为质数"""
    if k > n:
        return 0
    
    # 预处理阶乘
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i-1] * i % p
    
    # 计算阶乘的逆元
    inv_fact = [1] * (n + 1)
    inv_fact[n] = pow(fact[n], p-2, p)  # 费马小定理
    
    for i in range(n, 0, -1):
        inv_fact[i-1] = inv_fact[i] * i % p
    
    # 计算组合数
    return fact[n] * inv_fact[k] % p * inv_fact[n-k] % p
```

### 6. 注意事项

- **适用条件**：模数 $p$ 必须是质数
- **限制**：$n$ 和 $k$ 必须小于 $p$（否则需要使用卢卡斯定理）
- **时间复杂度**：预处理 $O(n)$，查询 $O(1)$

### 总结

费马小定理通过提供 $a^{p-2} \equiv a^{-1} \pmod{p}$ 这一关系，让我们能够高效地计算模质数下的逆元，从而将组合数中的除法转化为乘法，实现组合数的高效求模计算。
