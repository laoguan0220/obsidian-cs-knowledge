# 带权并查集

## 1. 基本思想

普通并查集只能判断两个元素是否在同一个集合，**带权并查集**在此基础上维护每个节点到其祖先的**相对权值**（距离或差值），从而可以推导出同一集合内任意两个节点之间的具体关系。

### 重要前提
- 每个节点存储到**当前祖先**的权值 `dist[x]`。
- 合并时，**永远将一棵树的根挂在另一棵树的根上**，保证 `dist` 更新公式成立。
- 只有同一集合内的关系才能确定；不同集合的节点关系未知。

---

## 2. 核心操作

### 2.1 `find(x)` – 路径压缩 + 权值更新

```cpp
int find(int x) {
    if (parent[x] != x) {
        int root = find(parent[x]);          // 递归找到祖先
        dist[x] += dist[parent[x]];          // 累积权值（注意加法顺序）
        parent[x] = root;                    // 路径压缩
    }
    return parent[x];
}
```

> **注意**：`dist[parent[x]]` 在递归后已经被更新为原 parent 到祖先的权值，因此直接累加即可。

### 2.2 `union(x, y, val)` – 合并两个元素的关系

假设已知关系：`weight[x] - weight[y] = val`（即 `x` 到 `y` 的权值为 `val`）。

```cpp
bool unionSets(int x, int y, int val) {
    int rx = find(x), ry = find(y);
    if (rx == ry) {
        // 检查已有关系与给定关系是否一致
        return (dist[x] - dist[y] == val);
    }
    // 将 rx 的祖先挂在 ry 上
    parent[rx] = ry;
    // 更新 dist[rx] 使得 dist[x] - dist[y] = val
    // 推导: dist[x] + dist[rx] - dist[y] = val → dist[rx] = val - dist[x] + dist[y]
    dist[rx] = val - dist[x] + dist[y];
    return true;
}
```

#### 推导过程（可配合一维数轴理解）

将每个节点映射到数轴上的一个点：
- 记节点 `x` 到原点的距离为 `pos[x]`，则 `dist[x] = pos[x] - pos[parent[x]]`。
- 已知 `pos[x] - pos[y] = val`，合并后 `pos[x] - pos[ry] = dist[x] + dist[rx]`，`pos[y] - pos[ry] = dist[y]`，联立解得：
  ```text
  dist[rx] = val - dist[x] + dist[y]
  ```

## 3. 常见模型与例子

### 3.1 区间差值 / 前缀和

当题目给出形如 `sum(l, r) = S` 的条件时，可以定义 `prefix[i]` 为前 `i` 项和，则条件转化为 `prefix[r] - prefix[l-1] = S`。用带权并查集维护 `prefix` 数组的相对值即可。

### 3.2 种类关系（模运算）

若关系有模意义（如奇偶性、循环节），权值定义为对 `M` 取模的值，更新和检查时做模运算即可。

## 4. 注意事项

1. **合并方向**：`parent[rx] = ry` 还是 `parent[ry] = rx` 会影响 `dist` 更新公式，必须统一并依据题目给定的关系正负来写。
2. **初始化**：`parent[i] = i; dist[i] = 0;`
3. **压缩时机**：任何查询操作前都应当调用 `find` 保证路径压缩，否则 `dist` 可能不准确。
4. **权值为负**：当左端点 `l` 到右端点 `r` 的权值是负值时，只需将 `val` 取反再传给 `union` 函数即可。
