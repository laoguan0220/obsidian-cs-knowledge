## 适合线段树解决的问题特征

线段树适用于以下场景：

### ✅ 核心特征

| 特征 | 说明 | 典型例子 |
|------|------|----------|
| 区间查询与单点/区间更新 | 需要高效维护序列上的区间操作 | 区间和、区间最值、区间赋值 |
| 信息可合并（满足结合律） | 两个子区间的信息可以快速合并成整个区间的信息 | $sum = left.sum + right.sum$ |
| 支持混合操作 | 可同时对区间执行多个操作（如加法和赋值），需注意运算兼容性和标记优先级 | 区间加 + 区间赋值 |
| 支持历史信息/版本 | 可持久化线段树或维护历史最值 | 历史最大值、回滚操作 |

### ❌ 不适合的场景

- 全局查询（如整个数组的 sum），用前缀和或树状数组更简单  
- 信息无法快速合并（如需要求区间中位数，除非平衡树）  
- 频繁的**全序列覆盖**且不需要区间细分  

### 代码示例（区间和 + 区间加）

```cpp
struct SegTree {
    int n;
    vector<long long> sum, add;
    SegTree(int n) : n(n), sum(4*n), add(4*n) {}
    void maintain(int o) { sum[o] = sum[o<<1] + sum[o<<1|1]; }
    void apply(int o, int l, int r, long long v) {
        sum[o] += v * (r-l+1);
        add[o] += v;
    }
    void push(int o, int l, int r) {
        if (add[o]) {
            int mid = (l+r)/2;
            apply(o<<1, l, mid, add[o]);
            apply(o<<1|1, mid+1, r, add[o]);
            add[o] = 0;
        }
    }
    void range_add(int o, int l, int r, int ql, int qr, long long v) {
        if (ql <= l && r <= qr) { apply(o, l, r, v); return; }
        push(o, l, r);
        int mid = (l+r)/2;
        if (ql <= mid) range_add(o<<1, l, mid, ql, qr, v);
        if (qr > mid) range_add(o<<1|1, mid+1, r, ql, qr, v);
        maintain(o);
    }
    long long query_sum(int o, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return sum[o];
        push(o, l, r);
        int mid = (l+r)/2;
        long long res = 0;
        if (ql <= mid) res += query_sum(o<<1, l, mid, ql, qr);
        if (qr > mid) res += query_sum(o<<1|1, mid+1, r, ql, qr);
        return res;
    }
};
```
